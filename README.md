# 🚗 Porsche Sales Dashboard

## 📊 Sobre o projeto

Este projeto consiste no desenvolvimento de uma **dashboard interativa para análise de 100 vendas de veículos da Porsche**, utilizando HTML para criar uma experiência visual dinâmica e personalizada, com maior liberdade de design em comparação aos gráficos tradicionais do Excel.

A proposta é transformar uma base de dados estruturada no Excel em um painel interativo, capaz de facilitar a exploração dos dados, identificar padrões de vendas e gerar insights relevantes para a tomada de decisões.

O projeto combina a organização dos dados no Excel com o apoio do ChatGPT para desenvolver a interface em HTML, utilizando o Canvas para visualizar e interagir com a dashboard.

## 🎯 Objetivos

* Transformar dados brutos de vendas em informações visuais claras e intuitivas.
* Desenvolver uma interface interativa com maior liberdade de personalização visual.
* Facilitar a análise do desempenho comercial por diferentes dimensões.
* Identificar tendências, padrões e oportunidades a partir dos dados.
* Demonstrar como a inteligência artificial pode apoiar o desenvolvimento de soluções para análise de dados.

## 🛠️ Tecnologias e ferramentas

* **Microsoft Excel:** preparação, organização e estruturação da base de dados.
* **HTML:** desenvolvimento da interface visual da dashboard.
* **ChatGPT:** apoio à criação do código, à estruturação dos indicadores e à implementação dos recursos interativos.
* **Canvas:** ambiente de visualização e interação com a dashboard durante o desenvolvimento.

## 📌 Funcionalidades

### Filtros interativos

A dashboard permite explorar os dados por meio de filtros que facilitam a segmentação das vendas:

* **Porsche Model:** modelo do veículo vendido.
* **Model Year:** ano do modelo do veículo.
* **City:** cidade da venda.
* **Pay Method:** método de pagamento utilizado.

Os filtros permitem analisar diferentes recortes da base e observar como os indicadores e gráficos se comportam conforme os critérios selecionados.

### Indicadores e perguntas de negócio

O painel foi desenvolvido para responder a perguntas relevantes para a análise comercial:

1. **Quais são os principais modelos de veículos vendidos por cidade?**
2. **Qual ano-modelo apresenta o maior volume de vendas em determinado período?**
3. **Quais padrões e tendências podem ser identificados na base de vendas?**
4. **Como as vendas estão distribuídas por estado?**

Essas análises ajudam a compreender a distribuição geográfica das vendas, identificar os modelos com maior participação e explorar o comportamento comercial sob diferentes perspectivas.

## 📈 Principais benefícios

* Visualização de dados mais dinâmica e personalizada.
* Navegação intuitiva por filtros interativos.
* Análise de vendas sob diferentes perspectivas.
* Maior facilidade para identificar padrões e oportunidades.
* Aplicação prática de inteligência artificial no desenvolvimento de dashboards.

## 🔄 Etapas de desenvolvimento

1. **Preparação dos dados:** organização da base com os registros das 100 vendas no Excel.
2. **Definição das perguntas de negócio:** identificação das questões que a dashboard deveria responder.
3. **Desenvolvimento com IA:** utilização do ChatGPT para gerar e ajustar o código HTML.
4. **Construção da interface:** personalização dos gráficos, indicadores, filtros e elementos visuais.
5. **Validação e exploração:** interação com a dashboard para analisar os dados e verificar os resultados apresentados.

## 💡 Aprendizados

O desenvolvimento deste projeto permitiu explorar novas possibilidades para a visualização de dados, demonstrando que o Excel pode ser utilizado como ponto de partida para soluções mais flexíveis e personalizadas.

A combinação entre uma base estruturada, perguntas de negócio bem definidas e o uso da inteligência artificial possibilita criar dashboards com uma experiência visual diferenciada, ampliando as formas de explorar e interpretar informações comerciais.

## 🚀 Conclusão

Este projeto demonstra uma abordagem prática para transformar uma base de vendas em uma ferramenta interativa de análise, unindo a organização de dados no Excel à flexibilidade visual do HTML e ao potencial da inteligência artificial.

Mais do que apresentar números, a dashboard busca facilitar a interpretação dos dados e apoiar a identificação de informações relevantes para a análise do desempenho de vendas.
